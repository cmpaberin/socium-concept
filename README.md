# Socium website concept

An unofficial concept build for **Socium** (socium.team), produced by **LocalEnhance**
as part of a proposal.

This is **not** the live Socium website and is not affiliated with or endorsed by Socium.
It is served with `noindex, nofollow` and a blanket `robots.txt` disallow so it can never
compete with or be mistaken for the real site.
